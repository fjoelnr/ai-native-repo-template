# ANR Ecosystem Registry

This registry contains reusable components for AI Native Repositories (ANR).

It is intended to collect shared building blocks that can be reused across projects.

## Registry areas

- `registry/skills/` reusable reasoning patterns for coding agents
- `registry/workflows/` reusable development procedures
- `registry/guardrails/` reusable constraints and operating boundaries
- `registry/examples/` example repositories and reference implementations

Starter packs:

- `startup-os` solo-builder and startup operation pack
