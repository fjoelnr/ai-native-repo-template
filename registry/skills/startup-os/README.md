# Startup OS Skills

This pack contains reusable ANR-compatible skills for solo-builder and small-team startup workflows.

These are not replacements for legal, finance, or executive accountability.
They are operational accelerators with explicit boundaries.

Included skills:

- `rapid-prototyper`
- `spec-writer`
- `growth-experimenter`
- `qa-reviewer`
- `analytics-interpreter`
- `compliance-precheck`
