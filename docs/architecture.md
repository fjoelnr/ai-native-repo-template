# Architecture (v0.1)

This repository is a minimal AI-native template.

## Purpose

It provides a stable foundation for projects where humans and AI coding agents collaborate.
The focus is clear context, safe boundaries, and reusable execution patterns.

## How agents interact with the repository

1. Start with `AGENTS.md`.
2. Use `.agents/context-index.md` for navigation.
3. Pick a workflow from `.agents/workflows/`.
4. Apply skills from `.agents/skills/`.
5. Respect constraints in `.agents/guardrails/`.

## Template building blocks

- `skills`: reusable reasoning processes
- `workflows`: repeatable task procedures
- `guardrails`: rules and forbidden zones
- `templates`: module-level context patterns

This keeps agent behavior predictable and reviewable across projects.
