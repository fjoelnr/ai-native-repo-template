# AGENTS.md

## Purpose

This repository collects agentic design patterns as runnable, testable, and continuously improvable examples.

It is intended to be a pattern lab, not a framework showcase or a list of prompts.

## Repository Map

- `src/patterns/` pattern implementations and small runnable demos
- `tests/` smoke tests, regression checks, and evaluation harnesses
- `docs/` pattern notes, comparisons, and design rationale
- `.agents/` workflows, skills, and guardrails for maintaining the repository

## Working Rules

- keep each pattern isolated and easy to run
- keep framework-specific examples comparable
- document assumptions, tradeoffs, and known gaps per pattern
- add tests or evals when behavior changes
