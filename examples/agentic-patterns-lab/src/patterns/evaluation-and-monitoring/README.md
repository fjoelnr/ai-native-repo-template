# Evaluation And Monitoring Pattern

This directory holds examples that turn agent execution into measurable outcomes.

Suggested contents:

- readiness evaluators
- goal monitors
- regression scoring
- trace summaries

Seeded examples:

- `goal-monitor.js` demonstrates a lightweight readiness evaluator
- `tests/evaluations/framework-evals.js` demonstrates fixed regression evals for framework-backed tracks
- the framework eval fixtures now include negative and edge cases, not just happy paths
